# My-First-Game
Shriyan OS

Shriyan OS is a custom web-based operating system built with HTML, CSS, and JavaScript. It features a desktop environment with interactive app icons, draggable windows, a live clock, and applications such as Shriyan Hub and Library Of Ohara.This OS is somewhat based on One Piece, an anime, and also contains information about me and my interests.I used HTML,CSS and Javascript for this project.I also used some AI(ChatGPT) to help with some bugs and the <span> element.What I added aditionally is the date option and much more in the advanced app.The goal of Shriyan OS was to create something that feels more like an actual operating system rather than a normal website. It includes a desktop environment, application icons, movable windows, a taskbar, a live clock, and interactive applications.

How to Run Shriyan OS

Shriyan OS is a web-based project, so it does not require a traditional installation.Simply open the project's live demo in a supported web browser and interact with the desktop.

Library Of Ohara

Library Of Ohara is one of the applications included in Shriyan OS. It can be opened directly from the desktop and demonstrates how applications can run inside their own windows.
The application also helped me experiment with images, interactive elements, and custom window layouts.

Shriyan Hub

Shriyan Hub acts as another application inside the operating system and is designed to demonstrate how multiple independent applications can exist within the same desktop environment.

Why I Built This

I created Shriyan OS as a way to learn more about web development, JavaScript, UI design, and interactive interfaces.
Instead of making a traditional website, I wanted to challenge myself to create something that behaves more like a real operating system. This meant learning how to manage multiple windows, handle user interactions, create draggable elements, and organize different applications inside one interface.
The project also gave me the opportunity to experiment, make mistakes, redesign parts of the interface, and gradually improve the operating system as I learned more. One of the major challenges I faced was using JavaScript which i had very little expirience in so with this project i learned how to integrate it into HTML and how to actually make it function.
